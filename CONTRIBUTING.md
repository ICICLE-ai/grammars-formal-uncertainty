# Contributing

The original repository for this project is [`DebarghaG/grammars-formal-uncertainty`](https://github.com/DebarghaG/grammars-formal-uncertainty). The ICICLE fork tracks its `main` branch.

- Submit changes to the project through [upstream pull requests](https://github.com/DebarghaG/grammars-formal-uncertainty/pulls).
- Report bugs and request project features through [upstream issues](https://github.com/DebarghaG/grammars-formal-uncertainty/issues).
- For changes to the ICICLE catalog metadata or the fork's CI and sync workflows, open a pull request in the [ICICLE fork](https://github.com/ICICLE-ai/grammars-formal-uncertainty/pulls).
